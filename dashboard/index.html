How the value is worked out

Each category's multiple is the market's own: the median market-cap-to-TVL ratio of the protocols in this same snapshot whose token already trades (three or more of them, else the snapshot-wide median), clamped to 0.05–2.50. No protocol name is ever special-cased — the same formula scores every row. A protocol "records no token" when DefiLlama's record carries no market cap, no CoinGecko id and no symbol; that is not proof it has none.
